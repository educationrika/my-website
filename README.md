# 中学理科 教材アーカイブ

中学理科の授業や復習に使えるWeb教材の置き場です。
ブラウザ上で動作するシミュレーションやドリルなどを公開しています。

## サイトURL
<!-- ここに公開URLを記載してください -->
[中学理科 教材アーカイブ](https://educationrika.github.io/my-website/)


## 収録コンテンツ

### 中学3年生
- **天体シミュレーター** (`astro_simulation.html`)
    - 地球の公転・自転と、季節・時刻による星座の見え方を確認できるシミュレーション教材です。

### 中学2年生
- **化学反応式クイズ** (準備中)
    - 酸化・還元などの化学反応式のドリルです。

### 中学1年生
- **植物の分類マップ** (準備中)
    - 被子植物・裸子植物などの分類を学ぶコンテンツです。

## 構成
- `index.html`: 教材一覧（メニュー）
- `style.css`: 共通スタイルシート
- `astro_simulation.html`: 天体シミュレーション本体

## 使い方
1. `index.html` をブラウザで開きます。
2. 使いたい教材の「開く」ボタンをクリックします。
3. 教材ページから「メニュー」ボタンで一覧に戻れます。
